# Nexus Office Downloads

This repository contains only Nexus Office desktop installer archives. It does not contain the application source code.

Download the ZIP for your operating system from [Releases](https://github.com/Nexus-Office-room/Nexus-Office-Downloads/releases/latest):

- **Linux:** Ubuntu/Debian `.deb` or portable `.AppImage` installer.
- **macOS:** choose the Apple Silicon or Intel `.dmg` inside the ZIP.
- **Windows:** `.exe` setup wizard or `.msi` installer.

The web app links directly to the matching installer archive. The source repository is separate and private.
